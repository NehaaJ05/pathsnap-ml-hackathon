Limitations and team handoff

The .route files are chronological arc sequences, not per-observation labels. The implemented labels are uncertain proxies, with explicit exclusions. Monotone alignment permits forward skips and has no speed penalty; repeated routes and disconnected references can still create errors. The report separately measures distance to any reference arc and distance after alignment. No classification, HMM or final-evaluation accuracy is claimed by this work.

Member 2 should use only FEATURE_COLUMNS, join labels within each trip, exclude ineligible observations, group CV by trip, and fit preprocessing inside folds. Member 3 should reuse the identical inference extractor and candidate policy; reference labels must stay out of prediction and UI responses. The integration team can add Member 1 dependencies from docs/requirements-member1.txt to the project-wide environment and incorporate these EDA sections into its consolidated report.

Existing model-training, optimization, evaluation, HMM, API and UI source files were not implemented or overwritten. The shared report/final_report.pdf placeholder is not presented as a completed full-project report. No Git commit or push was made.

96.682% of adjacent timestamp differences are exactly one second. The largest observed gap is 153,064 seconds. Such gaps must reset motion/decoder assumptions. No observations were silently reordered or interpolated. 0 observations were rejected by preprocessing.

The trip coordinates span longitude -100.418538 to 137.237029, latitude -34.640291 to 61.699590. A single local CRS would be inappropriate; per-trip UTM projections are used. Weak connectivity varies by trip, and directed reachability cannot be inferred from weak-component membership alone.

Duplicate arcs and self-loops retain original IDs. Zero-length arcs are excluded from candidates. 14 consecutive reference-arc pairs are disconnected by directed endpoint identity; no artificial connecting arcs are created.

Candidate features and reference coverage

Default policy: exact segment distance, radius 50 m, maximum 8 candidates, nearest fallback flagged when the radius contains none. All 23 model inputs are reference-free.
